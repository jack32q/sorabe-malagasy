# SORABE (سُورَابِ) — L'Écriture Ancestrale Malgache

Une application web interactive dédiée à la préservation, l'apprentissage et la transcription du **SORABE**, le premier système d'écriture historique de Madagascar.

## 🌟 Fonctionnalités

* **Générateur de Carte Calligraphique :** Saisissez votre nom pour générer et télécharger une carte en haute définition avec le sceau officiel Sorabe.
* **Quiz Interactif :** Testez vos connaissances sur l'histoire des Katibo, le papier Avoha, l'alphabet et les règles phonétiques.
* **Transcripteur Latin ➔ Sorabe :** Conversion instantanée du texte du malgache/français vers la graphie Sorabe.
* **Abécédaire (Abidy) :** Guide complet des consonnes et équivalences phonétiques.
* **Histoire Détaillée :** De l'installation des Arabo-Musulmans à la préservation moderne au XXIe siècle.

## 🛠️ Technologies Utilisées

* **HTML5 / JavaScript (ES6)**
* **Tailwind CSS** (CDN)
* **HTML5 Canvas API** (génération d'images)
* **Google Fonts** (Amiri, Cinzel, Inter, Scheherazade New)
